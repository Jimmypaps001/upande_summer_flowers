{{ _("The flow") }}

{{ _("Planning runs backwards. The market names a week it wants stems; everything else is that week minus a number the protocol states.") }}

  1. 1

    {{ _("Market Demand") }}

    {{ _("One register per variety per farm. Stems wanted, week by week, plus the grade split.") }}

    Summer Flower Market Demand · Summer Flower Demand Week · Summer Flower Demand Grade

  2. 2

    {{ _("Crop Protocol → Version") }}

    {{ _("The variety's characteristics at that farm: density, weeks to first cut, the flush schedule, the material route. Approving a protocol freezes a Version, and the plan is built against that frozen snapshot.") }}

    Crop Protocol · Crop Protocol Version · Crop Material Stage · Summer Flower Protocol Flush

  3. 3

    {{ _("Production Plan") }}

    {{ _("One button on the register. Walks the season week by week, and for every week still short proposes a planting sized to close it — then credits that planting's later flushes forward so it does not plant twice for the same gap.") }}

    Summer Flower Production Plan · Summer Flower Plan Block · Summer Flower Plan Week

  5. 4a

    {{ _("Get the plant material") }}

    {{ _("The route says where material is bought and how long it takes to become a plant in the ground. Bought material goes through the buying documents; own-raised material goes through propagation.") }}

    Material Request → Purchase Order → Purchase Receipt

    Summer Flower Propagation Plan · Summer Flower Motherstock Batch

    4b

    {{ _("Give it ground") }}

    {{ _("Allocation, not planning. The plan states what the market needs whether or not a block is free; blocks are assigned afterwards and a planting too big for one block is split.") }}

    Block · Bed · Planting Calendar · Bed Work Order

  7. 5

    {{ _("Plant, and record what happened") }}

    {{ _("The plan is an intention. A Crop Cycle is the actual planting in the actual bed, and harvest is recorded against it.") }}

    Crop Cycle · Stock Entry (harvest)

  8. 6

    {{ _("Budget") }}

    {{ _("Approving the plan values it: stems by grade, at the register's price per stem, per month and per block.") }}

    Summer Flower Budget · Block Production Budget

{{ _("Protocol governs actuals. Change the protocol and every plan built from it changes on the next regenerate — which is why a Version is frozen at approval rather than read live.") }}

{{ _("Step by step") }}

{{ _("1. Enter the demand") }}

{{ _("You do:") }} {{ _("Open Summer Flower Market Demand → New. Name the variety and the farm — together they name the register. Fill the weekly stems, and the grade split as percentages.") }}

{{ _("Watch for:") }} {{ _("One register per variety per farm. The same variety at a second farm is a second register, not a duplicate. If the horizon is short of your target years, Extend Horizon seeds the missing weeks from last year's shape.") }}

{{ _("The ⓘ icon") }} {{ _("on the form runs a walkthrough of every field, so the form itself stays clean.") }}

{{ _("2. Make sure a protocol is in force") }}

{{ _("You do:") }} {{ _("Open the Crop Protocol for that variety and farm and approve it. Approval writes a Crop Protocol Version — a frozen snapshot — and the plan is built against that.") }}

{{ _("What it must state:") }} {{ _("plants per bed, weeks from planting to first cut, weeks from sticking to planting, weeks in ground, turnaround, the flush schedule, and the material route.") }}

{{ _("Minimum planting size is entered as area, not as plants") }} — {{ _("the system rounds it up to whole beds, because a bed is the unit that gets planted.") }}

{{ _("3. Build the plan") }}

{{ _("You do:") }} {{ _("On the register, click Create Production Plan and pick the season. The farm is not asked for — the register already names it.") }}

{{ _("You get first:") }} {{ _("a preview. It tells you what would be built, what would block it, and the date the first order is already due, before anything is written.") }}

{{ _("A season") }} {{ _("runs 1 July to 30 June. Week 27 onward belongs to the year it starts in.") }}

{{ _("4. Order the material, allocate the ground") }}

{{ _("Order:") }} {{ _("the plan states what to buy and the last date it can be ordered, worked back through the route from the stage the material is bought at.") }}

{{ _("Allocate:") }} {{ _("blocks are assigned after the plan exists. A plan with no ground still builds, and says how many plantings are waiting on a block.") }}

{{ _("5. Approve") }}

{{ _("You do:") }} {{ _("Submit for Approval → Approve. Approving rebuilds the propagation plan and produces the budget. Sourcing is deliberately not committed before approval.") }}
